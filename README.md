## Heliactyl-rs

> [!NOTE]  
> This is Heliactyl Next version 15.0.0-dev.

> [!IMPORTANT]  
> This is a very very early version of Next 15 and is only supported running in development mode at this time. Not much is really implemented, but things work.


### Repository

- `server-rs` — API
- `client` — Frontend (Vite)

## Changes made by Heliactyl Rust.

- config.heli file with a custom syntax that's easy to understand.
- Upto 90% faster compared to stock heliactyl. 
- Easy & extensible Modding capabilties (Using HeliScript)
- Out-of-box load balancing.
- Axum Based (Async out of the box.)
- Not single threaded. 
- Uptime monitoring
- System Status monitoring.
